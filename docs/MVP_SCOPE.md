# MVP Scope — Nexus

## Definição
O MVP é o conjunto mínimo que representa o Nexus como produto sério de mercado, sem depender de expansões futuras para justificar valor.

## Inclui

### Camada Pública
- [x] Landing page institucional
- [x] Pricing
- [x] Termos e privacidade
- [x] Contato

### Camada Autenticada
- [x] Auth (email/senha + Google)
- [x] Dashboard
- [x] Onboarding
- [x] Hoje (visão do dia)
- [x] Perfil
- [x] Configurações
- [x] AI Mentor / Chat IA
- [x] Atlas Scanner
- [x] Anamnese
- [x] Prescrição
- [x] Clientes
- [x] Nexus Lab
- [x] Acadêmico
- [x] Biblioteca
- [x] Uploads
- [x] Loja
- [x] Billing
- [x] Performance

### Camada Admin
- [x] Painel admin com tabs (overview, uploads, users, atlas, integrations, logs, settings)

### Infraestrutura
- [x] Supabase Auth com RLS
- [x] Storage com URLs assinadas
- [x] Edge Functions (AI chat)
- [x] Profiles com auto-criação
- [x] User roles (admin, moderator, user)

## Exclui do MVP
- Mobile nativo
- Multilocação enterprise
- Marketplace de terceiros operacional
- Automações de payout avançadas
- Integrações fitness profundas
- Stripe billing real (scaffold preparado)
