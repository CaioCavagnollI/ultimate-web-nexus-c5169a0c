# Blueprint do Produto

## Camadas do Nexus

1. **Aquisição** — website, pricing, editorial, scanner público, store
2. **Ativação** — auth, onboarding, dashboard, mentor, scanner
3. **Operação Principal** — anamneses, prescriptions, library, uploads, lab, clientes, billing
4. **Retenção e Valor Expandido** — performance social, editorial, academic, store, admin, mentorias pro

## Fluxo Principal
```
visitante → cadastro → onboarding → dashboard → anamnese → prescrição → scanner → acompanhamento → billing/upgrade
```

## Diferenciais
- Governança de fontes alinhada ao conteúdo autoral
- Scanner Atlas incorporado (visão computacional)
- Camada científica (lab, editorial, acadêmico)
- Design premium com identidade editorial
- Combinação de operação profissional e monetização digital
